# Hi, I'm floppyist.

I'm a software developer since 2013, currently working as a system administrator. My main interests are Rust, web technologies and stuff closer to the system.

I enjoy building software across the whole stack, from backend logic and data storage to frontend interfaces. Rust is my go-to language for backend and systems work, while Vue is what I usually reach for when building web UIs.

I'm particularly fond of self-hosted applications, local-first software and tools that solve real problems without becoming unnecessarily complicated.

My approach to development is pretty straightforward: I like understanding how things work under the hood, not just getting them to work somehow. I care about maintainable code (mostly lul), sensible architecture and being able to trace problems from the frontend all the way down to the underlying system.

AI tools are part of my workflow, mainly to speed things up, explore ideas and handle repetitive tasks. They're useful tools, but understanding the code is still my responsibility. I want to be able to debug, modify and maintain anything I work on without depending on AI to do it for me.

Most of all, I enjoy building things, figuring out how to make them work well and learning something along the way.

Feel free to have a look around.
